# TRAINING TYPESCRIPT
https://udemy.com/course/typescript-grundlagen/learn/lecture/47315805

## How to setup
```
npm install
```

## How to run
To compile the index.ts file, run the following command:
```
npx tsc
```

To watch for changes and compile automatically, run the following command:
```
npx tsc --watch
```

## How to create a tsconfig.json file
```
npx tsc --init
```

## How to run the compiled file
To run the compiled file, run the following command:
```
node dist/index.js
```
To watch for changes and run the compiled file automatically, run the following command:
```
node --watch dist/index.js
```
